How does this work?

Each class's denominator is its documented commissions from public sources. Graduates report their own status through a GitHub issue form; a maintainer approves each report before it's counted. Everyone who hasn't reported is “unreported” — nothing is estimated or extrapolated.

Reports are self-selected and unverified, so they aren't a representative sample. Only aggregate counts are published; no names appear here. Download the aggregate CSV or see the repository.
